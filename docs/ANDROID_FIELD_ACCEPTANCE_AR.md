# اختبار Samsung — غير منفذ بعد

الجهاز المستهدف S22 Ultra SM-S908E، Android 16، RAM 8GB. لا يساوي نجاح Host اختبار الهاتف.

| الفحص | المطلوب |
|---|---|
| التثبيت والتحديث | مقارنة الشهادة والهوية، وحفظ بيانات أي نسخة قديمة |
| التشغيل والتنقل | فتح مساحة العمل دون Firebase إلزامي، العربية RTL |
| الصور | الكاميرا، المعرض، اختيار متعدد، الدوران، بقاء الأصل |
| ZIP | صور صحيحة، ملف تالف، حدود الأحجام، منع العبور |
| الاتصال | HTTPS حقيقي، توكن، انقطاع الشبكة والتعافي |
| المحركات | بحث ومراجعة مصدر وحقوق، تعديل مباشر وعزل مستقلان |
| الدفعات | نتائج تدريجية، إغلاق وفتح التطبيق، إلغاء وإعادة محاولة |
| التصدير | الأصليات والمخرجات والبيانات وZIP ومشاركة الملفات |
| الموارد | RAM، حرارة، تخزين وزمن معالجة على حمل فعلي |

كل البنود أعلاه تحتاج تجربة فعلية. لا يوجد هاتف متصل في بيئة التنفيذ.
